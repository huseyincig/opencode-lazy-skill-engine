# Architecture

`src/core/` contains pure or bounded-I/O TypeScript modules independent of any orchestrator. `src/plugin.ts` is the OpenCode V2 server adapter, and `tsc` + `scripts/emit-tui.mjs` compile the package into `dist/`.

- **Catalog (`src/core/catalog.ts`, `src/core/scanner.ts`)**: Combines native `ctx.skill.list()` entries (computing SHA-256 `contentHash` when source content is provided) with opt-in local vault roots; native entries take precedence over same-ID vault entries. Native entries without `path` are checked against `.opencode/skills/<id>/SKILL.md` and `.opencode/skill/<id>/SKILL.md`, and custom `roots` inside the project directory are classified as `origin: "project"`. Uses first-key-wins bounded frontmatter reads (with inline `#` comment stripping, duplicate-key diagnostics, and YAML anchor/tag rejection), streaming `opendir` traversal with `SKILL.md` budget pinning, optional `O_NONBLOCK` + `dev`/`ino`-verified sidecar metadata (`lazy-skill.json` / `skill.meta.json`), bounded synthetic identifier/heading derivation for strict `name + description` skills, fingerprint-checked index reuse on unchanged TTL refreshes, and atomic index rebuilds on edits or forced refreshes.
- **Search (`src/core/rank.ts`, `src/core/text.ts`, `src/core/concepts.ts`)**: Unicode normalization, camelCase/acronym splitting, expanded EN/TR stopwords, script-aware tokenization, conservative Turkish/English suffix stemming, 38-concept 13-language bridge (preserving CJK domain terms), inverted postings index, adaptive strict-frontmatter BM25F scoring (non-empty field length averages, per-token metadata saturation, shared catalog prefix dampening, IDF-prioritized long queries up to `64` terms, post-coverage `exactId` bonus), and full-coverage-first bounded Top-K retrieval.
- **Selection (`src/core/selection.ts`)**: Enforces required/explicit binding precedence (ignoring negated `-skill:<id>` and quoted prose references), automatic candidate allowlists, adaptive role baseline binding (`baselineMode: "adaptive" | "always" | "fallback"` via `resolveBaselineMode`, excluding untrusted `project` provenance from automatic baselines), negative triggers (including >150-token single-word vetoes and unspaced CJK phrases), origin bonuses, and coverage/score thresholds; `lazy_skill_plan` mirrors `prompt` hook permission/mesh/scope filtering, and synthetic/internal turns skip automatic binding.
- **Native Session Skill Reuse (`src/core/reuse.ts`, `src/core/session.ts`)**: Enabled by default (`sessionReuse: true`). On follow-up turns with a prior native attachment record and source `contentHash`, queries `ctx.session.context({ sessionID })` (1000ms timeout) and proves the host-prepared skill text is still present and unchanged across up to `1,000` recent messages (64 entries / 1 MiB fail-closed cap, 5s clock tolerance + `messageID` matching). Fails closed to fresh attachment on any mismatch, missing hash, lookup failure, `session.compaction.started`/`ended`, `session.deleted`, `skill.updated`, or `plugin.updated` (`reuseEpoch` guard).
- **Host Permissions (`src/core/host-policy.ts`)**: Reads ordered `skill` permission rules from `ctx.agent.list()` using linear glob matching. Missing records never synthesize grants. Session identity is resolved even under `mode: "single"` or `autoBind: "off"` when `ctx.agent.list()` is present, failing closed on transient lookup failures. Roster lookups are TTL-cached.
- **Coexistence (`src/plugin.ts`, `src/bridge.ts`)**: Existing `prompt.skills` arrays are preserved; default mode (`coexistence: "respect"`) avoids automatic additions when attachments are already present. Catalog hiding/compaction is opt-in, while `hints: "hint"` provides non-intrusive suggestions respecting `negativeTriggers` and permissions; `nativeCatalog: "hide"` injects on-demand discovery guidance via `ctx.session.hook("context")`. Universal Plugin Mesh interoperability (`src/bridge.ts`, `BRIDGE_REVISION = 2.3.1`) registers the `skills.catalog` capability, shares `queryMeshSkills`, deduplicates turn-level binding via `claimPromptSkillBinding`, verifies provenance with `isTrustedMeshMessage(..., sessionID)`, protects injected vault bodies (`kind: "skill-injection"`), and cleans up session state on `session.deleted`.
- **Vault Security & Resources (`src/core/security.ts`, `src/core/resources.ts`)**: Native skills attach via `event.prompt.skills`; global vault contents attach on demand when `vaultAutoBind: true` and project vaults require explicit `projectAutoBind: true`. `boundedOpen` enforces `lstat` pre-check, `O_NONBLOCK`, `fstat` `dev`/`ino` equality, Linux `/proc/self/fd/<fd>` canonical containment, `2s` `.unref()` read deadlines, binary rejection, and XML closing-tag boundary escaping. Resource listing bounds visited entries (`2,000`) and walk time (`1s`) with optional truncation diagnostics (`listResourcesWithDiagnostics`).
- **Semantic Selection (`src/core/semantic.ts`)**: Disabled by default (`semantic.enabled: false`); when enabled and host `experimental.generate.text` (or `ctx.generate.text`) is available, performs strict JSON ID selection (with markdown code-fence stripping and `providerID/modelID[#variant]` or active session model fallback) over bounded role-approved candidates with a 128-entry LRU cache.
- **TUI & Stats RPC (`src/tui.tsx`, `src/stats-rpc.ts`)**: `src/stats-rpc.ts` defines the typed `opencode-lazy-skill.stats` RPC contract (`snapshot` returning `version`, `catalogVersion`, `ready`, `skills`, `native`, `vault`, `local`, `global`, `conflicts`, `conflictIds`). `src/tui.tsx` registers the collapsible `LazySidebar` widget into `sidebar.content`, deduplicating in-flight RPC calls, scoping requests to the active `location`, refreshing immediately on `plugin.updated`/`skill.updated`/session changes with an adaptive 30s connected safety poll (5s while connecting), and skipping no-op Solid signal updates via `sameSnapshot()`. `scripts/emit-tui.mjs` emits `dist/tui-runtime.js` (OpenCode shared Solid runtime), `dist/tui-standalone.js` (standalone `@opentui/solid`), and adaptive `dist/tui.js`.
