# Architecture

`src/core/` contains pure or bounded-I/O TypeScript modules independent of any orchestrator. `src/plugin.ts` is the OpenCode V2 server adapter, and `tsc` + `scripts/emit-tui.mjs` compile the package into `dist/`.

- **Catalog**: Combines native `ctx.skill.list()` entries with opt-in local vault roots; native entries take precedence over same-ID vault entries. Native entries without `path` are checked against `.opencode/skills/<id>/SKILL.md` and `.opencode/skill/<id>/SKILL.md`, and custom `roots` inside the project directory are classified as `origin: "project"`. Uses bounded frontmatter reads (with inline `#` comment stripping and YAML anchor/tag rejection), optional symlink-safe sidecar metadata (`lazy-skill.json` / `skill.meta.json`), bounded synthetic identifier/heading derivation for strict `name + description` skills, and atomic index refreshes.
- **Search**: Unicode normalization, camelCase/acronym splitting, script-aware tokenization, conservative Turkish/English suffix stemming, 38-concept 13-language bridge (preserving CJK domain terms), inverted postings index, adaptive strict-frontmatter BM25F scoring (non-empty field length averages + per-token metadata saturation), and full-coverage-first bounded Top-K retrieval.
- **Selection**: Enforces required/explicit binding precedence, automatic candidate allowlists, negative triggers (including unspaced CJK phrases), origin bonuses, and coverage/score thresholds; `lazy_skill_plan` mirrors `prompt` hook permission/mesh/scope filtering, and synthetic/internal turns skip automatic binding.
- **Host Permissions**: `src/core/host-policy.ts` reads ordered `skill` permission rules from `ctx.agent.list()` using linear glob matching. Missing records never synthesize grants. Session identity is resolved even under `mode: "single"` or `autoBind: "off"` when `ctx.agent.list()` is present, failing closed on transient lookup failures. Roster lookups are TTL-cached.
- **Coexistence**: Existing `prompt.skills` arrays are preserved; default mode (`coexistence: "respect"`) avoids automatic additions when attachments are already present. Catalog hiding/compaction and prompt hints are opt-in (`hints: "hint"` by default for non-intrusive vault/uninvoked suggestions, respecting `negativeTriggers` and permissions); `nativeCatalog: "hide"` injects on-demand discovery guidance via `ctx.session.hook("context")`. Universal Plugin Mesh interoperability (`src/bridge.ts`, `BRIDGE_REVISION = 2.3.1`) registers the `skills.catalog` capability, shares `queryMeshSkills`, deduplicates turn-level binding via `claimPromptSkillBinding`, verifies provenance with `isTrustedMeshMessage(..., sessionID)`, protects injected vault bodies (`kind: "skill-injection"`), and cleans up session state on `session.deleted`.
- **Binding**: Native skills attach via `event.prompt.skills`; vault contents attach only on explicit opt-in via bounded file reads with XML closing-tag boundary escaping. File containment and role gating are independent defense layers.
- **Semantic Selection**: Disabled by default; when enabled and host `experimental.generate.text` (or `ctx.generate.text`) is available, performs strict JSON ID selection (with markdown code-fence stripping and `model.variant` support) over bounded role-approved candidates with an LRU cache.

- **TUI & Stats RPC (`./tui`, `./rpc`)**: `src/stats-rpc.ts` defines the typed `opencode-lazy-skill.stats` RPC contract (`snapshot` returning `version`, `catalogVersion`, `ready`, `skills`, `native`, `vault`, `local`, `global`, `conflicts`, `conflictIds`). `src/tui.tsx` registers the collapsible `LazySidebar` widget into `sidebar.content`, deduplicating in-flight RPC calls, scoping requests to the active `location`, and refreshing on `plugin.updated`, `skill.updated`, and a 5s interval. `scripts/emit-tui.mjs` emits `dist/tui-runtime.js` (OpenCode shared Solid runtime), `dist/tui-standalone.js` (standalone `@opentui/solid`), and adaptive `dist/tui.js`.
